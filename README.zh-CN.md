# As Above, So Below（如在其上，如在其下）

> 一座连接占星、八卦与复杂系统的桥——可交互的思想实验。

把文章
[*占星术、八卦与复杂系统：寻找迷信与科学之间的桥梁*](https://dev.to/sanyaduan/zhan-xing-zhu-ba-gua-yu-fu-za-xi-tong-xun-zhao-mi-xin-yu-ke-xue-zhi-jian-de-qiao-liang-35hm)
的核心论证，做成一个**看得见、能动手**的活体模型——再给你一套工具去质疑它。

## 一句话说清这个思想

宇宙和人体**本质是同一类东西**：都是耦合的、动态的复杂系统。占星与八卦不是
"方向错了"，而是"工具太粗糙"——它们是对复杂系统做信号关联分析的古老尝试，
在今天以"多智能体系统"的形式被重新发现。

## 项目做了什么

两个系统，通过一座信号桥耦合：

- **宏观——天体系统（左）**：太阳、月亮、行星各自运行，各自发出一个周期性
  "信号"。太阳光是主导的、已确立的驱动力；行星只是微弱的、示意性的扰动。
- **微观——人体系统（右）**：六个智能体构成的小型耦合网络——昼夜节律钟(SCN)、
  褪黑素、皮质醇、情绪、能量、免疫——其中 Sun→SCN→褪黑素→情绪 这条链是
  *真实* 的因果路径。
- **桥（中）**：耦合两个系统的信号通道。

你能看到**涌现行为**：情绪、能量、褪黑素随昼夜周期振荡，SCN 被光照**同步**
（一个真实的复杂系统现象：同步/entrainment）。

### 控制面板

| 控制 | 作用 |
|---|---|
| 仿真速度 | 0.25× – 4× |
| 信号耦合 | 天↔人 耦合强度（0 = 断开，变成两个互不相干的系统） |
| 噪声 | 向人体网络注入随机性 |
| 怀疑模式 | 调暗未证实的（行星）路径，高亮已确立的太阳路径 |
| 打乱行星相位 | 重随机化轨道，展示相关性并不稳定 |
| 重置 / 暂停 | 重置模型 / 冻结时间 |

### 实时读值

情绪、能量、褪黑素、**昼夜同步度**（`r(光照, SCN)`，即同步现象）、以及核心的
**`r(宇宙, 情绪)`** 相关系数。

## 怀疑实验室（Skeptic Lab）

第二个标签页把文章的批判性反思做成了可交互的五个模块：

1. **相关性 ≠ 因果**——在这里因果图是*已知的*（因为我们写下了它）。太阳驱动
   情绪，行星毫无贡献。但一个只看"天空 vs 情绪"的天真观察者，仍能测出非零的
   "行星 ↔ 情绪" 相关——因为一切都是周期的，有限样本必然产生伪对齐。
2. **实时相关性**——对比 `r(行星, 情绪)` 与 `r(宇宙, 情绪)`。把噪声拉高或打乱
   相位：行星那个数字会剧烈跳动；太阳那个始终很高，因为它才是真实驱动力。
3. **过拟合（巴纳姆神谕）**——一个模糊到"永远都能对上"的星座运势生成器。这是
   过拟合，不是预测。
4. **证据阶梯**——每条论断实际处在哪一层：*已确立*（潮汐、褪黑素）、*前沿*
   （地磁活动 ↔ 心血管）、*臆测*（行星 → 性格）。
5. **幸存者偏差**——24 条预测，一键"只显示命中的"，看漏掉的那些如何悄悄消失。

## 诚实的免责声明

这是一个**示意模型，不是对占星的验证**。行星的因果权重被**刻意设为 0**，为的是
把观点说得足够锋利。现实中可能存在微小、尚未证实的物理耦合；文章的立场恰恰是：
*"方向也许没错，但工具远不够精确。"* 完整免责声明见应用页脚。
